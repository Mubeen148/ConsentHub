# ConsentHub — Traceable Test Cases Matrix

| Case ID | Feature Area | Scenario | Expected Result | Automated By |
|---------|--------------|----------|-----------------|--------------|
| `TC-AUTH-01` | Authentication | User signs up with valid email, strong password, name, and region | `201 Created`, `ch_access_token` (`HttpOnly; SameSite=Lax`) + `ch_csrf_token` cookies set, `USER_SIGNUP` audit log appended | Newman, Playwright |
| `TC-AUTH-02` | Authentication | Login with invalid password or non-existent email | `401 Unauthorized` with generic `"Invalid email or password"` (zero user enumeration) | JUnit, Newman |
| `TC-AUTH-03` | CSRF Security | State-changing POST/GraphQL request with `ch_access_token` cookie but missing/mismatched `X-CSRF-Token` | `403 Forbidden` with `code: "CSRF_TOKEN_INVALID"` | Newman |
| `TC-BANNER-01` | Regional Banner | First-visit anonymous visitor in `EU` (`GDPR`) requests `screen(CONSENT_BANNER)` | `BannerShell` has `bannerStyle: "MODAL"`, `dismissible: false`, optional purposes default `false`, symmetric `Accept All` & `Reject Optional` buttons | JUnit, Newman, Playwright |
| `TC-BANNER-02` | Regional Banner | Visitor in `US_CA` (`CCPA`) requests `screen(CONSENT_BANNER)` | `regime: "CCPA"`, `bannerStyle: "BANNER"`, optional purposes default `true` until `Do Not Sell or Share` / `Reject Optional` clicked | JUnit, Newman, Playwright |
| `TC-PREF-01` | Preference Center | End-user toggles individual purposes (`analytics: true`, `ads: false`) and attempts to disable `essential` | `essential` remains locked (`true`); optional choices persist in `consent_records` and append SHA-256 `proofHash` entries in `consent_history` | JUnit, Vitest, Playwright |
| `TC-HIST-01` | Consent Timeline | End-user views `/portal/history` after updating preferences | Chronological ledger entries display purpose name, `Granted`/`Withdrawn` badge, policy version, region, source, and `proofHash` | Newman, Playwright |
| `TC-DSAR-01` | Data Portability | Authenticated user clicks **Download My Data** (`GET /api/v1/privacy/export`) | Returns `200 OK` JSON attachment (`Cache-Control: no-store`) with profile, current consents, ledger receipts, experiments, and DSARs + logs `COMPLETED` `EXPORT` ticket | JUnit, Newman, Playwright |
| `TC-DSAR-02` | Data Erasure | User submits `DELETE` request without typing `DELETE MY DATA` vs with `DELETE MY DATA` | Missing phrase rejected (`400 CONFIRMATION_REQUIRED`); exact phrase creates `PENDING` `DELETE` ticket visible in user tracker and Admin DSAR queue | JUnit, Newman, Playwright |
| `TC-DSAR-03` | Erasure Fulfillment | Admin completes `DELETE` DSAR ticket (`processDataRequest`) | User PII redacted (`deleted-<uuid>@redacted.consenthub.invalid`), optional consents revoked (`SYSTEM_ERASURE`), prior `export_payload_json` scrubbed, active JWT invalidated | JUnit, Newman |
| `TC-POL-01` | Policy Re-Consent | Admin publishes new active policy version with `requiresReconsent: true` | Previously consented users immediately receive `needsReconsent: true` and `shouldShowBanner: true` | JUnit, Newman, Playwright |
| `TC-EXP-01` | A/B Experiments | Same `subjectKey` requests `CONSENT_BANNER` repeatedly across sessions | Deterministically receives identical sticky variant (`SHA-256 mod 100`), persists 1 `experiment_assignments` row, and increments `conversions` upon granting optional consent | JUnit, Newman, Playwright |
| `TC-SDUI-01` | SDUI Validation & Fallback | Server validates canonical 15 types & blocks `javascript:` URIs; client receives unknown `FutureWidget` type | Server rejects unsafe URI/type with `SduiValidationException`; client renders `UnknownComponentFallback` (`role="status"`) without crashing | JUnit, Vitest |
| `TC-ADMIN-01` | RBAC Enforcement | Regular `ROLE_USER` calls `adminAnalytics`, `adminAuditLogs`, or `publishPolicyVersion` | Rejected with GraphQL `FORBIDDEN` error | Newman |
| `TC-AUDIT-01` | Tamper-Evident Audit | Admin runs **Verify Cryptographic Chain** (`verifyAuditChain`) | Recomputes SHA-256 chain from genesis (`0000...0000`); returns `chainValid: true` under normal operation and `chainValid: false` if any row is tampered | JUnit, Newman, Playwright |
| `TC-SDK-01` | Embeddable SDK | External page `/sdk-demo.html` loads `/consent.js` with `X-API-Key`, renders banner, and records choice | `/api/v1/sdk/config` & `POST /api/v1/sdk/consent` succeed with valid key (`401` on invalid/revoked key), `ConsentHub.getConsent()` updates live | Newman, Playwright |
